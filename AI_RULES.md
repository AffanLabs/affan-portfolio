# AI_RULES.md — Rules for AI-Assisted Editing

These rules exist to protect this template from common AI mistakes.
Follow them any time you edit this codebase with an AI coding tool.

---

## ❌ NEVER DO THESE

### Routing

- **Never rename** `src/routes/__root.tsx` — TanStack Router requires this exact filename.
- **Never rename** `src/routes/index.tsx` — this is the homepage route file.
- **Never rename** `src/routes/projects.$slug.tsx` — the `$slug` pattern is part of the router API.
- **Never delete** `src/routeTree.gen.ts` — this is auto-generated by TanStack Router.
- **Never manually edit** `src/routeTree.gen.ts` — it is regenerated on build.

### Imports & Exports

- **Never delete an import** unless you have verified nothing else uses it.
- **Never rename an exported function** without updating every import of that function.
- **Never move a file** without updating all imports that reference it.

### Styling & Responsiveness

- **Never remove** Tailwind responsive prefixes (`sm:`, `md:`, `lg:`) — these control layout.
- **Never delete CSS custom properties** from `styles.css` — components rely on them.
- **Never add inline `font-size` or `color`** directly to JSX without checking for an existing token.

### Animations

- **Never remove** `data-fx`, `data-no-fx`, `fade-in-up`, or animation class names — they drive scroll effects.
- **Never remove** the `ScrollFx` component from `routes/index.tsx`.

### Accessibility

- **Never remove** `aria-hidden` attributes — they are intentional.
- **Never remove** `alt` text from `<img>` tags.
- **Never remove** semantic HTML elements (`<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`).

### Build & Config

- **Never delete** `vite.config.ts`, `tsconfig.json`, `wrangler.toml`, or `package.json`.
- **Never touch** `.wrangler/` or `.tanstack/` directories.
- **Never install packages** without checking if they are already in `package.json`.

## ✅ SAFE ZONES (always safe to edit)

| File                        | What you can change                                  |
| --------------------------- | ---------------------------------------------------- |
| `src/data/personalInfo.ts`  | All personal branding text                           |
| `src/data/projects.ts`      | Project list, slugs, content                         |
| `src/data/skills.ts`        | Skill groups and items                               |
| `src/data/services.ts`      | Service cards                                        |
| `src/config/siteConfig.ts`  | Section toggles, nav links, hero keywords, copy      |
| `src/config/themeConfig.ts` | Color palette docs (actual colors in styles.css)     |
| `public/`                   | Replace images (keep filenames or update data files) |

---

## ⚠️ EDIT WITH CAUTION

- `src/styles.css` — safe to change CSS variable values; unsafe to delete class definitions.
- `src/components/portfolio/*.tsx` — safe to tweak JSX structure; unsafe to remove animation hooks.
- `src/routes/projects.$slug.tsx` — safe to change layout; unsafe to change the route pattern.
